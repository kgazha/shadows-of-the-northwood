# QA-батарея «Моркхейма» (tools/qa)

Переносимый набор headless-QA стендов игры. Один вход:

```
node tools/qa/run_all.js               # всё
node tools/qa/run_all.js --only=mb_1   # выборочно (через запятую)
node tools/qa/run_all.js --list        # список стендов
node tools/qa/run_all.js --timeout=600 # лимит секунд на стенд (по дефолту 300)
node tools/qa/run_all.js --skip-import # не делать godot --import (если stage свежий)
```

Как устроено:
- Стаджинг по-умолчанию: `git archive HEAD -- pixel-rpg` → bsdtar-распаковка в
  `tools/appdata_qa/stage/pixel-rpg`. Рабочий каталог main НЕ читается и не трогается:
  не страшны грязный worktree и LF-инциденты (стаджинг из git-объектов). Все пути
  записи/очистки проходят `assertInside` — писать можно строго в свой изолированный
  каталог (правило после инцидента с `git archive|tar` в чужой worktree).
  Фолбэк `--stage=robocopy` — легаси-зеркало рабочего дерева (`/MIR /XD .godot .git`).
  Поверх стенда кладутся файлы из `stand/`, один `--import`,
  затем каждый стенд — отдельным процессом `godot --headless --fixed-fps 60 res://<scene>.tscn`.
- Изоляция: `APPDATA=tools/appdata_qa/app`, `LOCALAPPDATA=tools/appdata_qa/local`
  (user:// сейвы не лазают в реальную папку). Каталог покрыт `.gitignore` строкой `tools/appdata_*/`.
- Логи каждого запуска: `tools/appdata_qa/logs/<стенд>_<n>.log`.
- Вердикт: GREEN если распарсен fail==0; NO_PARSE/TIMEOUT — тоже RED. Код возврата 0 — все зелёные.

⚠ `--skip-import` — только пока содержимое main НЕ менялось. Стаджинг бережёт `.godot`
в stage, и кэш глобальных классов (`global_script_class_cache.cfg`) остаётся от старого
содержимого: все стенды, трогающие новые `class_name`, умирают с `Identifier "X" not
declared` (поймано: после мержа FirstHint падали qa_ng/мир целиком). Сменился main —
один прогон без `--skip-import` (~5–6 мин).

Добавить стенд: положить `X.gd` + `X.tscn` (сцена = 4 строки, Node2D + ExtResource скрипта)
в `stand/` и дописать запись в `manifest.json` (mode: `pf` pass/fail, `xy` pass/total,
`fails` только fail, `multi` суммирует все совпадения `ok/total` построчно; массив `run` —
цепочка сцен, парсится лог последней; seed-сцены писать первыми элементами).
