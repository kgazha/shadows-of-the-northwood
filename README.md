# Тени Северного Леса (Shadows of the Northwood)

Вертикальный срез пиксельной RPG: Godot 4.7.2, 640×360, единый рукописный пиксель (вся графика генерируется кодом в одной палитре), детерминированная генерация карт, QA-батарея из 1300+ проверок.

## Быстрый запуск (Windows 10/11)

1. Скачайте **Godot 4.7.2 (stable, win64)** — бесплатная сборка, установка не нужна:
   <https://github.com/godotengine/godot/releases/tag/4.7.2-stable>
   (файл `Godot_v4.7.2-stable_win64.exe.zip`, внутри один exe)
2. Распакуйте exe в `tools\godot\Godot_v4.7.2-stable_win64.exe` внутри клонированного репозитория (папку `tools\godot` создайте).
3. Дважды щёлкните `start-game.bat`.

Первый запуск занимает полминуты — игра один раз импортирует ресурсы (дальше — сразу). Другого программного обеспечения не требуется.

## Проверки

```
node tools/qa/run_all.js --timeout=240
```

Подробное описание стендов — [tools/qa/README.md](tools/qa/README.md); каноны визуального масштаба — [SCALE_CANON.md](SCALE_CANON.md).
