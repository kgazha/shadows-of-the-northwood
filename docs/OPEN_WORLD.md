# Открытый мир — роадмап фаз

Вердикт пользователя 16.11 22:55 (запрос) и 17.11 10:10 («фазу один делай,
приступай»). Автор роадмапа — капитан.

## Запрос пользователя (сущность)
Перемещение между локациями через открытый мир; типы локаций: снежная,
пустынная, степная, лесная, замок, подземелье; процедурная генерация локаций
и целей; тематические враги; в замке/подземелье этажи с ростом сложности;
рост сложности монстров с расстоянием от дома; увеличение масштаба локаций
и привязка камеры к игроку.

## Фазы (каждая — отдельная волна, вердикт-гейт между ними)
- **Фаза 1 (УТВЕРЖДЕНА 17.11): камера следует за игроком + масштаб локаций
  растёт.** Фундамент: без скроллящейся камеры остальное невозможно.
  - t64: Camera2D-риг во всех зонах (деревня, пещера, Пепелище, аршина):
    плавное следование, кламп по пиксельным границам зоны, зум 1,
    снап при смене зоны/резюме; HUD/курсор/клик-движение/миникарта не ломаются.
  - t65: расширение локаций (деревня+лес примерно в 1,5 раза по площади):
    детерминированный генератор, все POI/NPC/арки достижимы (BFS-метрика),
    GOLDEN-пины переснимаются честно (распаковка архива), масштабный канон
    SCALE_CANON не нарушается (юниты остаются 16px-кратными).
- **Фаза 2: карта мира.** Экран-«карта» с процедурной расстановкой локаций
  шести типов вокруг деревни, переходы, сохранение позиции мира.
- **Фаза 3: тематические враги + рост сложности от расстояния** (градирня
  по удалению от дома; локальные задания в точках интереса).
- **Фаза 4: замок и подземелье с этажами.** Этажность (лестницы/спуски),
  рост злости вниз/вверх, сундуки-наборы по этажам.

## Инварианты всех фаз
- один экран 640×360, zoom 1, юнит-масштаб hero=16px (SCALE_CANON);
- вся графика — код-ген, ноль растровых файлов (ART LAW);
- детерминизм: любой новый генератор — с явным сидом и золотым пином;
- NG+ нет (вердикт 17.11): смерть = обнуление забега; пепел — открытый вопрос;
- батарея зелёная перед каждым мержем, перепины только датированные.
