# Открытый мир — роадмап фаз

Вердикт пользователя 16.11 22:55 (запрос) и 17.11 10:10 («фазу один делай,
приступай»). Автор роадмапа — капитан.

## Запрос пользователя (сущность)
Перемещение между локациями через открытый мир; типы локаций: снежная,
пустынная, степная, лесная, замок, подземелье; процедурная генерация локаций
и целей; тематические враги; в замке/подземелье этажи с ростом сложности;
рост сложности монстров с расстоянием от дома; увеличение масштаба локаций
и привязка камеры к игроку.

## Фазы (каждая — отдельная волна, вердикт-гейт между ними)
- **Фаза 1 (УТВЕРЖДЕНА 17.11): камера следует за игроком + масштаб локаций
  растёт.** Фундамент: без скроллящейся камеры остальное невозможно.
  - t64: Camera2D-риг во всех зонах (деревня, пещера, Пепелище, аршина):
    плавное следование, кламп по пиксельным границам зоны, зум 1,
    снап при смене зоны/резюме; HUD/курсор/клик-движение/миникарта не ломаются.
  - t65: расширение локаций (деревня+лес примерно в 1,5 раза по площади):
    детерминированный генератор, все POI/NPC/арки достижимы (BFS-метрика),
    GOLDEN-пины переснимаются честно (распаковка архива), масштабный канон
    SCALE_CANON не нарушается (юниты остаются 16px-кратными).
- **Фаза 2: карта мира.** Экран-«карта» с процедурной расстановкой локаций
  шести типов вокруг деревни, переходы, сохранение позиции мира.
- **Фаза 3: тематические враги + рост сложности от расстояния** (градирня
  по удалению от дома; локальные задания в точках интереса).
- **Фаза 4: замок и подземелье с этажами.** Этажность (лестницы/спуски),
  рост злости вниз/вверх, сундуки-наборы по этажам.

## Инварианты всех фаз
- один экран 640×360, zoom 1, юнит-масштаб hero=16px (SCALE_CANON);
- вся графика — код-ген, ноль растровых файлов (ART LAW);
- детерминизм: любой новый генератор — с явным сидом и золотым пином;
- NG+ нет (вердикт 17.11): смерть = обнуление забега; **межзабеговое наследие
  (вердикт пользователя 17.11 ~15:25): ПЕПЕЛ СОХРАНЯЕТСЯ и ДОСТИЖЕНИЯ ГЛОБАЛЬНЫ
  НА ИГРУ. Обе половины уже соответствуют факту: ach.* — вечный мета-слой
  (запинено), вечный баланс пепла смертью не стирается. Нюанс экономики ЗАКРЫТ
  вердиктом пользователя 17.11 16:14 и починен (t70): 35% ЗАРАБОТАННОГО в погибшем
  забеге больше не догорает — заработанное инкассируется на 100% обоими путями
  (смерть и «Новая игра»); константы ASH_KEEP_* убраны, пин qa_mb R4 переписан
  датированно на «earnings survive death fully»;**
- батарея зелёная перед каждым мержем, перепины только датированные.

## Туман открытия карты мира (туман v1, 25.11 — вердикт пользователя
## «мировая карта сразу открыта — её должен исследовать»)
- Модель — `scripts/fog_of_war.gd`: discovered-битовка 96x60 (720 байт),
 Chebyshev-бёра. Радиусы: VIEW_R=10 (обзор при ходьбе, world._fog_tick),
  ARC_R=10 (стартовая clearing у спавна/арки — северяне в тумане),
  PORTAL_R=3 (вход в локацию открывает её портал и окрестности).
  Открытое не забывается; сброс — только общий вайп круга (_wipe_circle).
- Туман — НЕ СТЕНА (t59-уроки): геометрия/коллайдеры/проходимость его не
  видят, герой ходит свободно; слой — одна ImageTexture-вуаль (клетка=1px,
  x16 NEAREST, CHAR-рампа + shash-шум) над пропами, z=900; перерисовка только
  на reveal-событиях. Ноль растров, GOLDEN-WM-PIN не двигается.
- Гейт порталов: клетка портала в тумане — E не срабатывает, подсказка
  «Место туманное» (WorldPortal.get_hint/try_interact). Вход в саму локацию
  любым путём открывает портал; возврат через арку/портал наружу дозволен
  всегда.
- Сейв: ключ "wm_fog" (base64 720 байт) — аддитивно к v4. Легаси без ключа =>
  wm_fog == null: туман ВЫКЛ, прежний сейв играет открытой картой (без
  регрессии опыта); новый круг/смерть/«Новая игра» — туман включён.
- Миникарта: та же вуаль поверх тайлов/блипов (C_FOG), блипы туманных
  порталов не загораются.
- QA: qa_world W8 (28 проверок: арифметика, base64, live-посев 294 клетки,
  ровно +441 на клетку ходьбы, гейт/подсказка, reveal при входе, disk
  roundtrip, легаси-null, геометрия туман не видит).
