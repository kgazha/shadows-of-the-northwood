## Правила коридора
- Всех «новых» чисел (строки 1, 2, 6, 7, 8) — ровно пять, каждое проверяется пином
  при проводке; пишем их в один реестр (GOLD_QUEST_TREES=20, GOLD_QUEST_SLIMES=30,
  PRICE_RESIN=15, PRICE_TORCH=25, PRICE_POTION=30) — проводка Г1.2–Г1.5.
- Доход главы = сумма строк 1–4 при зачистке обязательного контента; ±15% (78–106) —
  приёмка сквозного прогона (С1).
- Цена факела-крафта (15) обязана быть строго ниже готового (25): крафт учит,
  покупка страхует; разницу 10 не менять без вердикта.
