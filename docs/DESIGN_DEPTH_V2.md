# Глубина v2 — проект дизайна (25.11, на утверждение)

Ответ на вердикты живого плейта 24.11: «прогресс не чувствуется», «нет лута и
необходимости в предметах», «локации пустые: нет уровней, новых мобов, квестов».

Принципы unchanged: вертикальный срез, код-арт без растров,hero 16px zoom 1,
батарея-гейт, датированные перепины, вердиктные листы перед интеграцией арта.

## 1. Аффиксы — душа лута
Редкости (цвет имени/рамки в UI):
- обычная (белый) — без аффиксов, текущее поведение 1:1;
- добротная (синий) — 1 аффикс, шанс дропа 15%;
- реликтовая (фиолетовый) — 2 аффикса, шанс 5%, гарантирована в 1 сундуке
  микро-подземелья и в финале квестовой цепочки пояса.

Пул аффиксов v1 (8, все — готовые множители в существующие пути статов,
без новых полей боя): урон +10/15%, броня +1/2, крит +2%, скорость +5%,
золотой лут +10%, получение лечения +10%, кулдаун skills −10%, max мана +15%.

Детерминизм: ролл аффиксов от shash(run_seed, cell, drop_ordinal) — тот же
канон FNV, что у мира; повторный дроп в той же клетке того же сейва не
дублирует предмет (флаг сундука/моба уже есть). Эконом-вилки BALANCE.md
пересчитываются: цена продажи = price × (1 + 0.5×кол-во аффиксов).
Сейв: у предмета добавляется массив аффиксов; отсутствие = обычная
(обратная совместимость v4 без миграции).

## 2. Микро-подземелья ×6 (по одному в биомной локации)
Паттерн деревня→пещера, перенесённый в биомы: внутри локации появляется
E-интерактор «ход» (виден, не в тумане после открытия локации).
Внутри: 3–4 комнаты из тайлсета биома (генерация от сидов локации),
мини-босс пояса в последней комнате, сундук с реликтовым роликом.
Граница риска: это НОВЫЕ внутренние сцены — карта мира и геометрия существующих
локаций не двигаются (GOLDEN-WM-PIN целы; перепины только своих зон).
Смерть внутри = обычный конец забега. Возврат: выход тем же интерактором.
Мини-боссы (6): скелет-рудокоп (подземелье), степной застрельщик (степь),
песчаный червь (пустыня), снежный шептун (снег), краденый рыцарь (замок),
корневой засадчик (лес). HP по действующей формуле поясов (BALANCE #11).

## 3. Квесты поясов
Один квестовый поярусный поток через доску объявлений (паттерн существующих
квестов, без нового UI-каркаса): заказчик — старейшина (цепочка по мере
открытия поясов), цель — в биоме (зачистить N, найти сундук, закрыть ход),
сдача — у доски. Награда: золото по вилке BALANCE + 1 гарантированный
реликт на финальном звене цепочки пояса. Журнал: минимальный список
(клавиша Q, кнопка в HUD — на листе), цели кликабельны в описании.
Сейв: квесты уже аддитивны (q.*), расширяются тем же механизмом.

## 4. Новый моб на пояс (6 штук)
Фундамент 15 вариков готов; каждый новый моб = знакомое поведение + один
новый приём: рудокоп кидает обломки (дуга), застрельщик отступает держя
дистанцию, червь выныривает по телеграфу, шептун лечит соседей (приоритет
убийства), рыцарь блокирует фронт (удар в спину ×2), засадчик прыгает из
мха (телеграф-шелест). Арты — лист-вердикт перед интеграцией (тот же
порядок, что «Ощущение v1»).

## 5. Проверка и порядок сборки
1) аффиксы (данные+дроп+UI+сейв) — чисто код, пины детерминизма 50 кейсов;
2) квесты поясов (данные+доска+журнал) — на существующих целях;
3) микро-подземелья (сцены+генерация+интеракторы) — по одному биому за шаг,
   перепины своих зон;
4) новые мобы — после листа;
5) регрессия: полная батарея после каждого шага, плейт qa_c1 дополняется
   «сходил в ход, убил мини-босса, сдал квест» для пояса 1.
