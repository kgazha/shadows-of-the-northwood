## 1. NG+ цикл («Круги Пепла»)

### 1.1 Триггер входа

После `cave_state == 4` (амулет сдан старейшине) в диалоге старейшины появляется
последняя реплика с действием **«Начать новый круг»**. Действие:
1. `GameState.flags["ng.wave"] = int(flags.get("ng.wave", 0)) + 1`
2. Сброс по таблице 1.2, выдача Пепла (таблица 4.1), `GameState.save_game()`,
   переход в деревню (world reset как при quickload).

Автоматически предлагать на 5-й минуте сессии, если `boss_defeated && !ng_pending` — не нужно;
только явное действие в диалоге (защита от случайного сброса).

### 1.2 Что переносится (таблица сброса)

| Состояние (поле GameState) | Переносится? | Комментарий |
|---|---|---|
| `gold` | ✅ 100% | Капитал — топливо нового круга |
| `gear` (weapon/armor) | ✅ 100% | Меч/топор/клинок, броня |
| `has_amulet` | ✅ | Талон пройденного круга (+4 max_hp, +1 dmg остаются) |
| `level`, `xp`, `xp_next`, класс | ✅ | Прокачка — «личность» сейва |
| `slime_kills`, `herbs_picked`, статистика | ✅ | Счётчики достижений |
| `flags["meta.*"]` (покупки Пепла, гл. 4) | ✅ | Мета-прогресс |
| `flags["ach.*"]` (достижения) | ✅ | |
| `flags["daily.*"]` (ежедневный бонус) | ✅ | |
| `flags["ng.wave"]` | ✅ (+1) | Номер круга |
| Квестовые флаги: `elder_quest`, `slime_quest`, `cave_state` | ❌ сброс в 0 | Сюжет играется заново (тексты уже в голове — реиграбельность за боем, не за диалогами) |
| `has_key`, `has_amulet_niche`/ниша, `door_opened` | ❌ сброс | Ключ/дверь генерятся заново |
| `boss_defeated` | ❌ сброс в false | Босс жив до убийства в новом круге |
| `chests_used` | ❌ [] | 2 сундука снова открыты (но на 1 круг — один раз) |
| `campfires_used` | ❌ {} | 3 костра снова полны |
| `materials`, `brewed_potions` | ❌ | Сумки пусты |
| Флаги сайд-квестов `q.*`, `q.got.*`, `q.last.*` | ❌ | Квесты Гриима/травника заново |
| `flags["meta.*"]`, `ng.*`, `ach.*`, `daily.*` | **НЕ трогать при сбросе** | Белый список переноса |

Реализация: `GameState.start_ng_plus()` — один метод (~40 строк), перенос = инверсия сброса.
Сигналов достаточно существующих (`quest_changed`, `gold_changed` → автосейв).

### 1.3 Скейл мобов по волнам (точные формулы)

Обозначим `w = ng.wave` (обычная игра w=0). Все множители применяются **в одном месте**:
при инициализации моба — `slime.gd::_ready()` и раздача `TIERS` в `brute.gd`.

```gdscript
# game_state.gd (новые чистые функции, читаются мобами на спавне)
func ng_hp_mult(w:int) -> float:   return 1.0 + 0.5 * w            # cap w=5 → ×3.5
func ng_dmg_add(w:int) -> int:     return int(ceil(w / 2.0))       # w1-2:+1, w3-4:+2, w5+:+3
func ng_xp_mult(w:int) -> float:   return 1.0 + 0.35 * w           # w5 → ×2.75
func ng_gold_mult(w:int) -> float: return 1.0 + 0.40 * w           # w5 → ×3.0
```

`hp = int(round(base_hp * ng_hp_mult(w)))`, `dmg = base_dmg + ng_dmg_add(w)`,
XP/gold — умножение результата броска перед выдачей. **Cap волны: w=5** (`NG_WAVE_CAP`),
дальше игра «на удержание» без цифр (иначе GL Compatibility WebGL упрётся в твин-таргеты).

| Моб (база v2) | w0 | w1 | w2 | w3 | w4 | w5 |
|---|---|---|---|---|---|---|
| Слайм hp3 / xp7 | 3/7 | 5/9 | 6/9 | 8/11 | 11/12 | 11/13 |
| Brute tier1 hp6/xp6 | 6/6 | 9/8 | 12/8 | 15/10 | 18/11 | 21/12 |
| Brute tier2 hp9/xp8 | 9/8 | 14/11 | 18/11 | 23/13 | 27/14 | 32/15 |
| Brute tier3 hp12/xp10 | 12/10 | 18/14 | 24/14 | 30/17 | 36/18 | 42/20 |
| Босс hp24 | 24 | 36 | 48 | 60 | 72 | 84 |

Проверка баланса урона: игрок на w5 с руническим клинком (×3) — воин 2×3+1(амулет)=7 ед/хит,
tier3 = 42 HP = 6 хитов (было 2). Смысл: танговать кувырком, не стоять.
Золото: wave5-проход ≈ 150 × 3.0 = 450g — быстрее всех покупок, это и есть награда за скилл.

`mat_drop` (0.25), скорости (`speed`), CD рывков — **НЕ масштабируются** (readability ударов).

### 1.4 Модификаторы босса по волнам (аффиксы)

Босс читает `flags["ng.wave"]` при спавне (`brute.gd`, ветка `is_boss`). Один аффикс = номер волны:

|---|---|---|---|
| 1 | Яростный | `BOSS_SPEED 34→40`, `BOSS_CHARGE_CD 4.0→3.2` | 1 ч (2 константы) |

| 3 | Токсичный | после рывка в точке приземления лужа r=22px: 1 dmg / 0.5 с, 2.5 с, макс 2 лужи | 3–4 ч (новая зона-ловушка) |

## 3. Ежедневный бонус (возврат через оффлайн-таймер)

### 3.1 Данные (в существующий JSON сейва, без миграции)

| Ключ `GameState.flags` | Тип | Смысл |
|---|---|---|
| `"daily.stamp"` | float | unix-время последней полученной награды, `Time.get_unix_time_from_system()` |
| `"daily.streak"` | int 0..7 | серия дней |

### 3.2 Логика (один вызов из `GameState._ready()` после `load_game()`, ~50 строк)

```gdscript
var now := Time.get_unix_time_from_system()
var last := float(flags.get("daily.stamp", 0.0))
var days := int(floor((now - last) / 86400.0))
if last == 0.0:                 days = 1        # первый запуск = старт серии
if now < last - 3600:           return            # часы назад (>1 ч) — молча НЕ награждать, stamp не трогать
if days >= 1:
    streak = 1 if days > 1 else mini(streak + 1, 7)   # пропуск дня обнуляет серию
    выдать награду по таблице; flags["daily.stamp"] = now
```

### 3.3 Награды серии (день → сброс после 7-го)

| День | Награда |
|---|---|
| 1 | +15g |
| 2 | +20g, 1 трава (herbs-заряд в сумку) |
| 3 | +25g |
| 4 | +1 к `brewed_potions` (заряд крепкого, в пределах `BREWED_CAP=2`) |
| 5 | +40g |
| 6 | +50g, +10 XP |
| 7 | +80g + **2 Пепла** (якорь на мета-валюту) |

Экономика: 250g + 2 Пепла в неделю = +1.7 прохода к шоп-лестнице за месяц — заметно, не ломает.

### 3.4 UI

Тост при заходе: «Ежедневная награда: … (серия N/7)». Иконку-счётчик в HUD — P2.
Стоимость блока: **3–4 ч** (без UI-панели).

## 4. Мета-прогресс «Пепел» (валюта NG+, траты у Гриима)

### 4.1 Заработок (всего ~8–13 Пепла за первый круг с заходом на w1)

| Источник | Формула/константа |
|---|---|
| Первое убийство босса в круге | +3 Пепла (`brute.gd::_die()`, флаг `"ng.boss_<w>"` от повторной выдачи в одном круге) |
| Ежедневный день 7 | +2 Пепла |
| Достижения №3,4,6,7,9,10,12 | 2+3+1+1+2+1+3 = **13** суммарно (разовые, через круги) |
| Итог реалистично к концу w1 | ~10–15 Пепла |

### 4.2 Траты — новая вкладка «Алтарь Пепла» в шопе Гриима

`shop.gd`: второй список кнопок (паттерн `CATALOG` уже есть), курс — Пепел вместо золота,
счётчик `GameState.flags["meta.ash"]` (int).

| id (`flags["meta.<id>"]` = кол-во покупок) | Эффект (перманентный, через NG+) | Цена | Шаг цены | Кап |
|---|---|---|---|---|
| `bless` | +1 max_hp навсегда (в `max_hp`-геттер: `+4*int(f)`) | 3 | +2 за покупку (3,5,7…) | ∞ |
| `master` | +10% урона: в `GearData.player_damage()` домножить `round(base*mult) → round(base*mult*(1+0.10*f))` | 5 | фикс | 3 (=+30%) |
| `purse` | +50g стартовый капитал при старте каждого NG+ | 4 | фикс | 2 (=+100g) |
| `greed` | +25% золота с мобов (применять в `Loot.on_mob_death` после `ng_gold_mult`) | 6 | фикс | 1 |
| `feet` | КД кувырка 0.9 → 0.75 с (`player.gd`) | 8 | фикс | 1 |

Суммарный «полный алтарь»: 3+5+5+5+4+4+6+8 = 40 Пепла ≈ 3–4 круга. Первый обязательный
апгрейд (`bless`×1 = 3 Пепла) доступен уже в конце w0 при зачистке достижений —
правильный первый выбор.

Стоимость блока: заработок **2 ч**, вкладка шопа + геттеры эффектов **5–6 ч**.

### 5.3 Главное решение одним абзацем
